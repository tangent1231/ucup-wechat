# 编辑器交付与证据

| 层级 | 可交付内容 | 验证重点 |
|---|---|---|
| 本地设计 | 多款布局、图组、SVG、可选动效 | 不等于公众号效果 |
| 可编辑正文 | 内联样式，百分比容器/图片宽度 | 文案、标题层级、字体、链接、无横向溢出 |
| 图片组合 | 独立原图和明确组合参数 | 不误裁人脸/Logo；不同日期不乱配 |
| 横滑与交互 | 编辑器原生组件或已验证的专用结构 | 导入、保存、手机滑动各自验证 |
| 视频 | 在线观看链接；需要时另交本地视频 | 富文本不能替代原生视频上传 |

富文本剪贴板用 text/html 与 text/plain 双格式。含图可用内嵌图片或用户可用的在线图片地址；目标编辑器可能过滤内嵌图片。区分“复制含图片成功”和“图片已进入目标草稿”。失败时交付单独素材和替换位置，不能承诺一次复制永远不丢图。

默认移交正文不依赖外部 CSS、JavaScript、浏览器 Grid/Flex、fixed/sticky、复杂背景；宽度百分比不等于必然兼容。实验效果若保留这些依赖，在输出说明中标为待验证。

本地 details 折叠不是公众号专用交互。安全导出移除 details/summary，全部章节展开，动效静态化。验收包括“全部收起后导出”与原始文图数量一致。GIF/静态封面可单独上传，注明封面内文字不可逐字编辑。

Markdown 用相对媒体路径打包；若已有 B站/YouTube 视频链接，可直接使用链接，避免要求读者拥有本地 MP4。用户指定的英文技术段落保持原文，引用用显式编号与链接呈现，确保渲染后仍可见。

保存源稿、素材映射及可复现的构建文件。稿件包只放可用交付物；调试截图与脚本可单独放校验目录。多渠道推广文案是独立产物，不因正文术语改动而擅改已定稿的社群版本。

发布是另一项动作。创建文案或复制到剪贴板不是发送授权；只有用户要求发布、发送或指定审批时才执行对应外部操作。
