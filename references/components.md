# 组件与样式

## 七个起点（可调整，非固定品牌规范）

- 赛事特刊：米白、墨蓝、少量红棕；衬线大标题，合影/场景全幅，首张大图加两张辅助图。适合年度总结和赛后报道。
- 科技赛场：深海蓝、冰青；无衬线标题、赛程节点，完整正文配横滑图组。本地横滑原型需目标编辑器另行验证。
- 社区纪实：暖白、赭橙；人物或现场细节先行，相册边框，成对竖图与收束横图。图组裁切需要逐图确认人脸和关键物件。

- 科创长卷：浅蓝紫渐变、环形与节点几何，主题封面、图形章节、白色正文面板和错落双图/横图。同一套图形语言贯穿首屏与章节。
- 气球庆典：蓝紫透明气球、相片贴纸、圆角章节，主图加两张辅助图。适合欢迎与相聚叙事。
- 代码手记：代码窗口插画、横线纸、等宽小标签、照片批注；成对图片与宽图交替。适合技术交流与经验回顾。
- 键盘工作台：立体键盘、薄荷网格、时间线节点和高低错位图组。适合从准备、思考到比赛的叙事。

## 完整构图与动效

先确定封面、导语、章节、图组和收尾的阅读节奏。背景保持低对比，标题装饰不要压住文字。错位图组仅在组合模式使用；完整图片模式不得加遮罩或裁切。

首屏图片可轻推镜或浮动；背景用缓慢渐变、轨道或节点，避免正文晃动。设置暂停、关闭及 prefers-reduced-motion。章节默认展开，支持键盘操作；不把关键信息藏在折叠内。

可另交静态封面和 GIF 封面作为上传素材；封面图中的标题不可逐字编辑。保留源 HTML 和可编辑正文，目标编辑器与手机端的动画表现仍需实测。

## 组件选择

全幅图用于地点/合影/关键节点；组合图用于同一段落的相关画面，避免把不同日期照片配到错误小节。保留原图，不为排版永久裁掉照片。

横滑图组保留一小段下一张预览并提供滑动提示。不要默认自动轮播。用实际触屏/拖动检查可达性，不只观察一张截图。

SVG 可用于线条、章节标记、时间节点等，品牌 Logo 不重绘。普通浏览器 SVG/CSS 动画与微信编辑器专用交互不是同一个实现。真实微信动效可考虑目标编辑器支持的组件或单独 GIF；静态替代始终可交付。

奖项信息：这个用户已拒绝窄列挤压的表格和过大的徽章底框。优先试简洁纵向条目、小奖杯/奖牌、独立金额与每人单位。名称约 15px、金额约 20px 可作起点；需依据新稿重新检查。

重点文字：少量加粗和下划线同时强调，不让整段都变粗。动态分隔线控制数量、速度，保留关闭动效的选项。

联合 Logo 页尾：让感谢语、图片及结束语共用一个深色容器，图片 display:block，去掉外层空段落。若目标编辑器仍产生白缝，单独渲染整块页尾图作为替代；明确该小块不再逐字可编辑。
