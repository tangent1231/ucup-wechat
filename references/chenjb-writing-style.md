# chenjb 文字风格

这是用户命名的 UCup 中文写作参考，依据用户于 2026-11-06 提供的三份文字样例提炼：AI 时代算法竞赛公益讲座报道、2026 UCup Finals 赛后回顾、Finals 开幕致辞。参考其表达方法，不将样例中的日期、成绩、职务、技术判断或人物发言当作后续文章的事实库。风格名称不表示新稿由 chenjb 本人撰写或认可。

## 叙事与立场

以赛事组织者和社区建设者的视角，认真解释“发生了什么、为什么值得关注、与参与者有什么关系”。语气正式但能让人感到具体的人在说话：有判断、有温度，也有持续投入社区的责任感。既写高水平竞技，也写教练、选手、出题人、志愿者和合作伙伴如何共同促成活动。

宏观意义由具体事实支撑。写一封欢迎信、一场交流、一次解题分享怎样影响参与者，再谈社区连接与人才培养；不在每段末尾重复升华。“我们”用于有来源支持的组织行动和立场，不能把个人推测写成 Universal Cup 的正式声明。

## 三类文章的不同推进方式

### 活动报道与赛后回顾

- 开头尽快交代时间、地点、活动、主办或邀请关系及参与者。第一次出现正式活动名称、人名、身份时写清楚；双语名称按素材需要保留。
- 先给读者最重要的结果或现场，再回到过程。赛后总结可以从闭幕与揭榜开篇，随后按日期回顾；不要把这一结构固定套给所有稿件。
- 叙事写出变化：从开局不利到调整，从封榜悬念到结果，从陌生队伍到交流。只有来源记录了变化才写，不能为了戏剧性补造逆转、掌声或对话。
- 重要队伍、贡献者与合作伙伴具体点名，角色、名次和归属分别核对。比赛之外的活动需要交代它怎样促成交流，而不只是列流程。
- 收尾由本次事实回到 UCup 的长期工作，再自然致谢与展望。情绪可以上扬，但避免把一次活动写成已经完成的宏大使命。

### 讲座报道与观点文章

- 先建立背景和真实问题，再解释观点如何回应它。一个核心问题足以组织一段，不用问题句填满全文。
- 常见推进是“现实变化 → 原有判断面临什么挑战 → 关键概念或区分 → 具体能力与实践 → 对竞赛和社区的意义”。保持因果链，不把观点堆成口号清单。
- 概念成对出现时解释区分标准，例如不同命题思路分别奖励或筛选什么能力；不为了句式强行制造二元对立。
- 问答适合保留直接的问题与完整回答。区分逐字引用、转述和作者分析；没有录音、讲稿或已确认原稿，不给嘉宾添加引号内发言。
- 涉及 AI 现状、竞赛成绩或研究突破时，核实当前来源。样例里“过去一年”“进入某年后”等相对时间，以及对能力的判断，不作为可重复使用的文案。

### 现场致辞

- 可以从感谢、重逢或共同经历开篇，使用有依据的第一人称和对现场听众的直接称呼。
- 用一条真实的思考线索串起成绩、困惑和下一步：回顾做过的事，解释它改变了怎样的认识，再提出方向。
- 具体行动比抽象自我评价更有说服力。既承认阶段性进展，也说明还有哪些工作需要完成；不虚构个人经历、承诺或组织计划。
- 结尾适度增加句子的节奏感，以感谢、邀请参与或对听众的祝愿收束。第一人称致辞不直接套用于第三人称新闻报道。

## 句子、段落与强调

- 每段推进一个主要意思，句与句之间能说清因果或递进关系。可用“这也意味着”“从这个角度看”“也正因如此”等连接，但不让每段都以相同连接词开头。
- 长句用于容纳事实和逻辑，短句用于落下判断或情绪；长短交替。样例中的长段落在公众号上可按语义拆段，不机械复制密集程度。
- 排比用于真正并列的能力、行动或愿景；反问用于推进真实问题；转折用于有证据的认识变化。避免连续套用“不是……而是……”或反复说“意义不止于比赛”。
- 加粗关键问题、核心判断和重要人名，少量使用。日期小标题、图片和图注帮助阅读，不把正文切成大量短口号或 PPT 式碎片。
- 竞技张力来自准确的过程，社区温度来自真实的人和行动。少用泛化的“圆满成功、赋能未来、共襄盛举”等词来代替信息。
- 简繁体、日期空格、英文队名及机构名按本篇要求统一。保持正式名称原样，不把样例中的 HTML 实体、转义反斜线、图片序号复制进成稿。

## 从素材到成稿

先建立本篇事实清单与主线，再选择适合的文体。资料充分时将结果、场景、解释和社区意义组织成连贯叙事；资料不足时保留待核对项或删去不受支持的细节，不为了风格补故事。

仅排版、校对或已定稿任务，保留原文。用户要求改写时，尽量保持原稿信息、立场和人物归属，避免用新的宏大结论替换原意。英文版保持相同论述结构，以自然英文重写句法，不硬译中文排比。

交付前回看：重要判断前是否有事实或论证？每段是否提供了新信息？人物发言是否有依据？去掉煽情词后文章是否仍然成立？结尾是否确实来自本篇内容，而非任何 UCup 文章都能粘贴的通用使命段？
