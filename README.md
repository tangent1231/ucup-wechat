# UCup WeChat Skill

用于 UCup 中文推文写作、改稿、排版与素材交付的可复用 skill。当前版本 **v0.4**。

## 包含什么

- **chenjb 文字风格**：从用户提供的活动报道、讲座文章与致辞中提炼叙事、论述和社区视角。
- **七款样式**：赛事特刊、科技赛场、社区纪实、科创长卷、气球庆典、代码手记、键盘工作台。
- **图片编排**：组合、横滑、纵向完整图片，以及换图、调序、裁切焦点和间距控制。
- **本地交互原型**：展开/收起、图片推镜、缓慢背景、可暂停动效及减少动态效果支持。
- **透明图标**：气球、代码窗口、机械键盘、装饰奖杯，各有原图、512px、160px 版本和生成提示词。
- **默认页尾**：UCup 二维码及用户指定的编辑排版、审核署名，可在每篇文章中覆盖。

入口是 [SKILL.md](SKILL.md)。文字规范见 [chenjb 文字风格](references/chenjb-writing-style.md)，图标见 [素材说明](references/icon-library.md)，页尾见 [页尾组件](references/footer.md)。

## 使用

将本仓库作为 `ucup-wechat` skill 目录使用。示例任务：

> 使用 $ucup-wechat，根据这份活动记录写一篇参考 chenjb 文字风格的 UCup 推文，保留事实与人物发言归属，并做科创长卷和代码手记两款排版。

只需要排版时请注明“原文已定稿，保留文案”。风格参考不是作者署名，不会自动把新稿署名为 chenjb。

## 构建样式预览

Python 3 标准库即可构建，无需安装第三方 Python 包。根据 [输入格式](references/lab-input.md) 准备本篇文章 JSON、素材清单和实际图片：

```sh
python3 scripts/build_lab.py article.json manifest.json --output preview.html
```

生成文件内嵌图片，可独立打开。若需剪贴板功能，可在输出目录启动本地 HTTP 服务再访问预览。工作台中可以切换样式和下载富文本 HTML；浏览器调整不会自动保存，刷新前请导出调整记录。

导出结构检查：

```sh
python3 scripts/audit_html.py exported-article.html
```

## 交付边界

本地浏览器预览不等于秀米或微信效果。默认富文本导出会展开全部章节、静态化动效并使用纵向完整图片。组合、横滑与折叠需要在目标编辑器适配，导入、保存和手机端表现分别验证。

AI 图标用于装饰，不能冒充官方标志、真实赛事照片或实际奖杯。二维码由用户提供，保持原图。赛事文案、日期、名次与人物观点必须以本篇来源核对，不把风格样例当作事实库。

本仓库提供通用模板、素材及工作方法，不包含本地聊天记录或整篇活动样稿。不会自动发布推文或联系他人。
